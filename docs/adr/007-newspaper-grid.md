# ADR-007 · 报纸排版用 A3 矩阵矩形装箱,不套用 8.1 的四种流式方案

- **状态**: 接受
- **Lab**: 8
- **日期**: 2026-08-26

## 上下文

手册 8.1 给出 Typst / Pandoc+XeLaTeX / WeasyPrint / Playwright 四条链路。它们解决的是「中文如何变成 PDF」,版心默认仍是博客式通栏或 CSS 多栏**流**——字从左上灌到右下,栏与栏之间断开,一篇稿很少拥有自己的矩形疆界。

真实报纸不是这样:一张固定尺寸的纸被栏线切成矩阵,每篇文章覆盖其中一块长方形;写长了就跳页(「下转第 3 版」),而不是把后面所有稿件往下挤。

家用打印机打不出卷筒新闻纸,A3(297×420 mm)是能买到的最大常见幅面,也接近小报(tabloid)一页。

本项目此刻没有稳定配图,但不能等图来了再发明规则。

## 决策

1. **版心自研**: `render/layout/` 把 A3 切成 6×14 格子,用 MaxRects(BSSF) 给每篇稿一块矩形。Typst/WeasyPrint/Playwright 都不做版心。
2. **落墨用 reportlab**: 只按已经算好的 mm 坐标画字。系统宋体/黑体 TTF,自写 CJK 折行,保证量字和画字同一套度量。
3. **HTML 是孪生输出**: 同一套坐标写成绝对定位 HTML,方便手机和「浏览器打印到 PDF」兜底。
4. **纸张 A3 纵向**: 可在普通打印机上缩印或专业店输出。不模拟卷筒宽幅。
5. **图井算法先落地**: 1–3 张图从文章矩形里切一块矩形图井,正文保持矩形;缩放、裁切、溢出到续页的规则写在 `images.py`。没有文件时画占位框。

## 为什么不直接用 8.1

| 方案 | 卡住的地方 |
|---|---|
| WeasyPrint + `column-count` | 栏是流,稿件没有矩形边界,续页无法对准某一块 |
| Typst 多栏 | 适合学术小册,跳页续稿和变宽矩形要手写大量 `#place` |
| Pandoc+XeLaTeX | 字体和报错成本高,版心照样是文章流 |
| Playwright 打印 | 分页控制弱,和「先切格子」相反 |

这四条仍然可以当**渲染器**,但我们缺的是编辑部的拼版,不是缺一个 HTML-to-PDF 驱动。

## 后果

- **正面**: 调试排版只看 `layout.json` 和格子,不必重跑 collect;图来了只填 `ImageSpec.src`。
- **负面**: 自研装箱会留下空洞(MaxRects 不是最优);不绕排意味着图多时正文区可能偏瘦。
- **成本**: 多一个 reportlab 依赖;macOS 用系统宋体,Linux 需要 Noto CJK,否则回退 CID 字体。

## 何时重新评估

1. 配图管道稳定且经常 3 张以上,再考虑 L 形绕排。
2. 若要「对开大报」而不是单张 A3,把 `PageGeom` 换成两页拼幅,算法不用改。
3. 若 reportlab 在某台机器上永远缺字,HTML 打印仍是合法归档路径。
